# Stormy-Pulse: 音乐可视化播放器

一款可视化的桌面音乐播放器，支持本地音频播放、高精度音频特征分析与实时可视化特效渲染（由 CPU 渲染），并支持视频导出。

## 🚀 快速开始

本项目使用 [uv](https://github.com/astral-sh/uv) 进行高效的依赖管理与项目打包。新用户只需以下三步即可直接运行：

### 1. 克隆仓库
```bash
git clone <repository_url>
cd Stormy-Pulse
```

### 2. 同步并安装依赖
在项目根目录下，执行 `uv sync` 会自动创建虚拟环境，并将当前项目以开发模式打包安装：
```bash
uv sync
```

### 3. 运行程序
同步完成后，使用下述命令一键运行播放器：
```bash
uv run music-visualizer
```
*(注：你也可以通过运行 `uv run main.py` 或 `uv run run.py` 来启动项目)*

## 🌐 WebUI 实时播放（浏览器访问）

除了桌面版，项目还内置一个 **FastAPI WebUI 服务器**，可以在浏览器里像本地播放器一样实时播放与渲染可视化，并支持硬件加速视频导出：

```bash
uv run music-visualizer-web          # 默认 0.0.0.0:7860
uv run python -m app.webui --port 7860
uv run main.py --web                 # 等价入口
```

启动后访问 `http://localhost:7860`（局域网内其他设备用服务器 IP 访问）。

- **实时播放渲染**：浏览器的 `<audio>` 元素负责播放时钟（音频完美同步、原生拖动/音量），后端按当前播放时间实时渲染确定性帧（本机实测 15~25 fps @720p）
- **上传即分析**：选择音频文件后自动开始特征分析（带进度条），可附带 `.lrc` 歌词；同一文件重复上传直接命中分析缓存
- **视觉 DNA 实时调参**：结构原型 / 色系 / 色相偏移 / 能量 / 混沌 / 明亮度等参数在播放中即时生效，所见即所得
- **视频导出**：与桌面版相同的导出管线（CPU 并行分段渲染 + FFmpeg），编码器经过实机试编码探测，导出完成后可直接下载

> 说明：WebUI 为单用户会话设计；渲染设置仅作用于浏览器会话，不会写入桌面版的持久化配置。

## 📦 特征缓存说明

首次播放某首歌曲时，程序会在后台完成完整的音频特征分析（L1~L5 特征，耗时与歌曲长度相关）；分析结果会持久化缓存，再次播放同一首歌时直接读取缓存，加载几乎瞬时完成（CPU / GPU 两种渲染后端共用同一份分析缓存）。

- **缓存位置**：项目根目录下的 `cache/` 文件夹（文件名形如 `v6_<hash>.npz`），方便直接查看和管理
- **识别方式**：按「文件名 + 文件大小 + 修改时间」识别歌曲，歌曲文件发生变化后会自动重新分析
- **清空缓存**：直接删除 `cache/` 文件夹即可，下次播放时自动重建
- **旧版本迁移**：早期版本缓存存放于 `~/.music_visualizer/cache`，启动时会自动迁移到项目目录并清理旧位置
